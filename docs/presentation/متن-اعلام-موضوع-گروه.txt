عنوان پروژه: طراحی و پیاده‌سازی سامانه وب رهیار برای پایش و مدیریت عملیاتی سامانه‌های میدانی
در این پروژه یک سامانه وب برای ثبت و نمایش اطلاعات سامانه‌های میدانی طراحی و پیاده‌سازی می‌شود.
کاربر می‌تواند سامانه‌ها را بر اساس استان و محور مشاهده کند و از طریق نقشه یا جست‌وجو به اطلاعات هر سامانه برسد.
سامانه امکان ثبت و مشاهده گزارش‌های روزانه، وضعیت سولار، رخدادها و سوابق اقدامات را فراهم می‌کند.
معماری پروژه شامل رابط کاربری وب، بک‌اند API و پایگاه داده است و دسترسی کاربران بر اساس نقش و محدوده سازمانی کنترل می‌شود.
هدف، یکپارچه‌سازی اطلاعات و ساده‌تر کردن پایش وضعیت و پیگیری اقدامات مربوط به سامانه‌هاست.

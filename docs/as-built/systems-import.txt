Rahcom Systems Excel Import

The systems import maps common English and Persian headers. The system code field accepts code, systemCode, sitecode, or stationcode; site names include stationname; coordinates accept lat/latitude and long/longitude/lng/lon. The province is taken from the selected top-header province. The workbook's «محور» and «کد محور» columns are stored as the announced axis name (`announcedAxis`) and announced code (`axisCode`). Operational assignment remains separate in `axis`. Details and equipment address fields are imported when present. Rows without a system code or valid coordinates are skipped; a blank site name falls back to the system code.

The supplied Ips Sobyar - با کد محور.xlsx workbook has 162 data rows. With its current contents, 136 rows have a system code and valid coordinates and can be imported. The remaining rows have blank codes or missing/invalid coordinates.

Implementation: src/app/(workspace)/rahcom/systems/rahcom-systems-list.tsx

The Systems page reads the province-scoped systems API for every province, including Isfahan. The tracked workbook at src/provinces/isfahan/isfahan-systems.xlsx is retained as a portable backup/reference file, not as the runtime source of truth. The Systems toolbar provides four separate actions: save a database snapshot as a machine-readable backup workbook; restore a backup workbook into the database; upload an external Excel workbook; and download the current user-facing systems list. A multi-province backup includes a province column and can be restored from the all-provinces view. A province-specific restore only imports rows for the selected province.

Saving a backup uses the browser's Save File Picker where available, with an appropriate suggested filename. Choose the tracked workbook path (src/provinces/isfahan/isfahan-systems.xlsx) to replace that local backup; browsers and hosted deployments cannot write directly into the Git repository. The downloaded/selected file must still be added to a commit separately if it should become part of a deployment. The database remains the live source, so changes made in Excel affect the system only after the workbook is restored/imported.

When the Systems page's traffic incident comparison is enabled, it also displays incident-marked traffic-list rows whose system code is absent from the Isfahan master workbook. These temporary rows use the selected date's traffic snapshot and do not write or create master system records.

Manual system creation: authorized users can add a system from the Systems toolbar when a specific province is selected. The compact form requires system name, system code, latitude, and longitude; it submits through the existing province-scoped systems import API, then refreshes the list. Isfahan uses the same province import path as its Excel-backed records.

System details page: the system information popup links to /rahcom/systems/[systemCode]?province=... . The page reads the province scoped system record and presents system identity, axis, coordinates, bill identifier, equipment IPs, incident/outage information, and notes. Users with Rahcom management permission can edit these fields; Isfahan saves through the systems import/upsert path, and other provinces use the system update endpoint.

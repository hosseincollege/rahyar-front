Rahcom axis sources

Rahcom keeps two classifications separate:

- Announced axes are the official axis name and Tehran-assigned code in the uploaded systems workbook. They are stored in `RahcomSystem.announcedAxis` and `RahcomSystem.axisCode`.
- Operational axes describe Rahyar's planned field corridors. They remain in `RahcomSystem.axis` and `RahcomAxis`, with Isfahan's recovery-safe corridor definitions in `src/provinces/isfahan.ts`.

In the systems workbook, the «محور» column maps to `announcedAxis` and «کد محور» maps to `axisCode`. Applying a daily traffic list also saves «نام ایستگاه» and «کد تجمیع» on the matching system by system code. These four announced/list fields are read from the system record after import, so changing the displayed traffic date does not change them. The «سرقت و تخریب» column remains a date-specific view of the selected traffic snapshot. Importing or applying a daily traffic list does not overwrite operational assignments. The systems list, map, and solar daily list offer separate announced/operational views. Isfahan's announced code/name pairs from the supplied workbook are recorded in `src/provinces/isfahan-announced-axes.ts`.

The additive Prisma migration `20261031200000_separate_announced_axes` adds the announced name field and copies existing named axes with a declared code into it, preserving the prior axis values during migration.

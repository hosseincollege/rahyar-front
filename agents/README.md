# Rahyar frontend preference guide

The user's approved and clarified preferences are grouped by the four frontend modules in the navigation and one shared area. Read this index and the relevant topic before changing a module or shared UI. Add each durable preference to the matching topic in the same task as the implementation.

## Modules

- [Rahcom](rahcom/README.md)
- [Documents](documents/README.md)
- [Settings](settings/README.md)
- [Development](development/README.md)
- [Shared UI](shared/README.md): theme, shell, top header, and behavior used across modules.

Each navigation option has its own same-named Markdown file in its module folder. Keep the index in sync when navigation options change. If a newer explicit preference replaces an older one, update the existing note so there is one current rule. These notes record user intent; they do not authorize unrelated changes.

# Theme and surfaces

- Use the existing theme variables and design tokens for primary, foreground, muted, border, and card colors. Interactions should work in both light and dark themes.
- Keep popovers and dialogs on opaque card surfaces. Do not add translucent glass effects, backdrop blur, or page dimming.
- For hover states, accent the intended control (such as its outline or icon) without changing nearby entered text or unrelated controls.
- Preserve Rahyar branding, shell layout, and approved page spacing. Make only the visual change the user requested.
